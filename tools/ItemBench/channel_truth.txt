# channel_truth.txt - the one truth table of the "Beta updates" switch (Companion 0.16.2; the beta channel plan's critic
# item 15, 2026-10-12). Which channel a reader takes from the environment variable YAZS_BETA and the Companion's
# config file BepInEx\config\bidoi.yazs.companion.cfg, section [Update], key BetaUpdates (a bool, default true).
# One file, three kinds of reader: the Companion's bench (UpdaterCases.cs), and every other program that follows the
# switch (an updater, another plugin) - each reads this file and must give every row's answer.
#
# The rules:
#   1. YAZS_BETA, any case: 0 off false no -> stable; 1 on true yes -> beta; unset, empty or anything else -> ignored
#      (rule 2 decides). The value is taken as it is: no trimming.
#   2. The config value, as BepInEx reads it: the [Update] section and the BetaUpdates key matched exactly (case
#      included), lines starting with # skipped, the text after the first = trimmed; true / false in any case -> that;
#      any other text (yes, 0, an empty value ...) -> true, BepInEx's own default for the key.
#   3. No file, no [Update] section, or no BetaUpdates key in it: the Companion binds the key (default true) -> beta;
#      a reader OUTSIDE the Companion -> stable (no setting: a machine whose Companion is older than 0.16.2 has none).
#
# Columns, separated by "|" (the spaces around each column are not part of it):
#   env        YAZS_BETA: <unset> (not in the environment), <empty> (set to ""), or the value as set
#   cfg        what the config file holds - the value written after "BetaUpdates = " in the file below, or one of:
#                <no file>        the file does not exist
#                <no section>     the file below without its [Update] section (and without the key)
#                <other section>  "BetaUpdates = false" under [General], and no [Update] section
#                <no key>         the [Update] section without a BetaUpdates line
#                <key case>       "betaupdates = false" in [Update] (the key in another case: not the key)
#                <commented>      "# BetaUpdates = false" in [Update] (a comment)
#                <empty>          "BetaUpdates =" with nothing after it
#   companion  the channel the Companion itself follows: beta | stable
#   outside    the channel a reader outside the Companion follows: beta | stable
#   from       what decided it: env (YAZS_BETA), cfg (the config value), missing (rule 3)
#
# The file a reader builds for a cfg value v (written with CRLF line endings, as BepInEx writes it on Windows and under
# Proton; a reader must accept LF as well):
#   ## Settings file was created by plugin YAZS Companion v0.16.2
#   ## Plugin GUID: bidoi.yazs.companion
#   <blank>
#   [General]
#   <blank>
#   ShowBadges = true
#   <blank>
#   [Update]
#   <blank>
#   ## At every launch, fetch the release feed ...
#   # Setting type: Boolean
#   # Default value: true
#   AutoUpdate = true
#   <blank>
#   # Setting type: Boolean
#   # Default value: true
#   BetaUpdates = v
#   <blank>
#   [Logging]
#   <blank>
#   Verbose = false
#
